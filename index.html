🎫 免作业次数（学期滚动累计）

规则：小组累计日常积分每满 5 分 折算 1 次 免作业机会，全组共享——小组折算 5 次，每位组员均获得 5 次。
扣分直接扣减本人免作业次数；兑换免作业时也会扣除相应次数；老师还可手动给个人加/扣免作业机会。
个人免作业次数 = 小组折算次数 − 个人被扣次数 − 已兑换次数 ＋ 老师手动调整（可为负，表示尚欠）。整个学期滚动累计，不按周/月清零。

✅ 免作业兑换

学生使用免作业机会时点击"兑换"，将从其免作业次数中扣除。兑换记录可撤销。

🎛️ 个人机会灵活调整（老师手动加/扣）

老师可针对个人灵活加减免作业机会，用于奖励、补偿或纪律处理。加/扣次数可自定义，可填写原因，记录可撤销。

👥 分组名单管理

名单已按 Excel 准确名单更新（803班6组、804班8组），陈亦朵、阙韵馨已删除。如需调整可直接修改。每行一名学生，空行表示空组。

📝 日常作业项目

每天可有多项作业，在此设置作业名称、增删项目。打卡时在作业页切换当前作业。

✍️ 默写过关内容

可添加多项过关内容（如生字听写、词语默写），打卡时切换当前内容，各项记录与全组过关奖励互相独立。改名会同步历史记录。

🥇 小组过关名次加分

小组全部过关按批次计名次，可自定义每个名次加几分（计入小组积分，5分折算1次免作业）。同批勾选的小组视为同时过关，得相同名次分。

⭐ 课堂表现项目

加分项计入日常积分，扣分项扣免作业次数。

💾 数据管理

数据保存在本机浏览器中。建议定期导出备份。

🔗 Supabase 共享数据库（可选）

填入 Supabase Project URL 与 anon public key 后，教师端和展示屏会直连你的 Supabase；留空则继续使用当前云端同步。需先在 Supabase 执行提供的建表 SQL。

☁️ 云端数据同步

填入你的 Supabase 项目地址和密钥，教师端与展示屏会直连同一个数据库，所有设备打开同一个链接即可共用同一份数据。不填则继续使用默认云端同步。

📌 如何获取：在 Supabase 项目后台 → Project Settings → API，复制 Project URL 和 anon public 密钥（不是 service_role）。使用请先在本项目执行已提供的 supabase_sync.sql 建表脚本。
